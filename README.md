# terminal-lm

A command-line based local LLM that turns natural language into executable bash commands.

Are you good at writing Bash scripts? Personally, I'm not. Unfortunately, a lot of the models that _could_ run those scripts AND have access to the terminal are paid.
So I made this. Qwen2.5-3B-Instruct fine-tuned with transformer architecture and QLoRA, trained on a dataset of Linux commands.
